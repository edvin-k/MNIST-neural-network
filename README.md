# Ed's Numpy Neural Network (EdsNNN)

The MNIST neural network repository provides code for neural network study. Various architerctures, optimizers, hyperparameter configurations and many more are made variables such we can have flexible comparison between different cases and recreate phenomena from known papers (ResNet etc..). This is an on-going project and all code provided is done in Python using only numpy with current input assumed to be the MNIST dataset and is expected to generalize to any dataset of 2D images grey-scaled.
